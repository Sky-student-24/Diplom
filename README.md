Описание проекта:
Интернет-магазин «Читай-город» – один из ведущих в России книжных магазинов.

Объект тестирования:
- Поиск книги по названию
- Добавление книги в корзину
- Просмотр книги из раздела “Новинки”


Сcылка на финальный проект в Younote:
"https://lesson-1.yonote.ru/share/2331da36-6350-4006-a5b8-82be909bb699"


Инструкция для проведения тестов:

1) Убедиться, что установлен Allure и плагин для Pytest:
pip install allure-pytest

2) Запустить тесты с генерацией отчета:
pytest путь/к/твоей/папке --alluredir=путь/к/папке/для/отчетов

3) Для просмотра отчета использовать команду:
allure serve путь/к/папке/для/отчетов
Эта команда откроет отчет в браузере.
